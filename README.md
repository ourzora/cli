# Zora CLI

This package is available at [@zorlabs/cli](https://www.npmjs.com/package/@zoralabs/cli).

The Zora CLI is a command-line tool for interacting with the Zora protocol — create, manage, and mint onchain media directly from your terminal.

## Getting Started

Visit **[cli.zora.com](https://cli.zora.com/)** for documentation and installation instructions.

## Source

The source code now lives in the [zora-protocol monorepo in packages/cl](https://github.com/ourzora/zora-protocol/tree/main/packages/cli) monorepo.
